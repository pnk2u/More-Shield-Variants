# <img width='24' src="./src/main/resources/icon.png"> More Shield Variants
> ![Mod Icon](https://raw.githubusercontent.com/pnk2u/resources/main/ModProjects/More-Shield-Variants/pres/logo/logo_c.png)
>
> A simple mod adding wood variants for Minecraft's Shield Item.

### Compatibility

- Minecraft: `1.20.1`, `1.21(.1)`, `1.21.4`~`1.21.9`
- Mod Loader: _Fabric_
- Requires: [`Fabric API`](https://modrinth.com/mod/fabric-api)

### ᴬ⃯ ᵦ⃔ Translations

Currently available in:
- English
- German
- Simplified Chinese (@[qiuqimc](/../../../../qiuqimc) with [PR #7](../../pull/7), added in [`1.3.1`](/../../#131))
- Ukrainian (@[StarmanMine142](/../../../../StarmanMine142) with [PR #10](../../pull/10)/[11](/../../pull/11), added in [`1.3.3`](/../../#133))

Want to help translate? Feel free to open a PR to the **default branch (`1.21(.1)`)**.
